3. Learning outcomes
Implement contiguous and linked data structures in software.
Melaksanakan struktur data bersebelahan dan berpaut dalam perisian.
Apply tree traversal and graph traversal algorithms to solve complex searching problems.
Mengaplikasikan algoritma lintasan pokok dan graf untuk menyelesaikan masalah carian.
Evaluate asymptotic time and memory complexity of computer algorithms.
Menilai kerumitan masa dan ingatan asimtotik algoritma komputer.
