Data Structures / Struktur Data
UMC · FTMK · Dr. Aina Zulkifli · Online, English

Need: Critical core computer science competence requested by industry.

Parent course: BITS 1123 Data Structures and Algorithms · 3 credits · 120 h SLT · Bachelor of Computer Science (Software Development) with Honours
Unbundling Model:
(a) Credit-Based Unbundling Model
Each module has at least 40 hours SLT and encompasses its own learning, activities, and assessment.

Modules: 1. Arrays and Linked Lists (40 h); 2. Trees and Graphs (40 h) — total 80 h

Learning outcomes:

LO1: Implement contiguous and linked data structures in software.
LO2: Apply tree traversal and graph traversal algorithms to solve complex searching problems.
LO3: Evaluate asymptotic time and memory complexity of computer algorithms.

Assessment: Module 1 Test: Linear Data Structures (30%); Module 2 Test: Non-Linear Structures (30%); Comprehensive Capstone Coding Project (40%)
