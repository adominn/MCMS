11.3 Critical Vulnerabilities & Architectural Issues

Critical Finding 1: Unprotected Asynchronous Processing in Grade Staging
Severity: High • Affected Route: POST /admin/ucreds/imports/{id}/stage • Module: MD-06
Staging imported grades from UCreds runs synchronously within the PHP-FPM web request. For cohorts exceeding 300 learners, database transaction duration risks exceeding the default 60-second execution timeout, potentially resulting in partial grade staging.
Remediation: Implement Redis queue worker dispatch (StageGradesJob) with atomic transaction rollback.
Critical Finding 2: Lack of Cryptographic Hashing on Stored Evidence Files
Severity: High • Affected Route: POST /quality/{mc}/evidence • Module: MD-10
SAMC Quality Verification evidence items currently accept textual URLs or file reference strings without computing or recording a SHA-256 binary hash. An altered external document would not invalidate the evidence chain.
Remediation: Connect file inputs to an S3-compatible object store that calculates and immutably logs the binary SHA-256 hash in qv_evidence.file_hash.
Critical Finding 3: Missing Official Senate Transfer Decision Letter (DOC-12)
Severity: Medium • Affected Route: GET /transfers/{id} • Module: MD-12
When a credit transfer is approved, the decision updates the credit ledger, but no official printable Decision Letter (DOC-12) is generated for the student or Pejabat Pendaftar.
Remediation: Implement transfer.letter Blade view adhering to layouts.print.

11.4 Prioritized Architectural Recommendations

Recommendations are structured into four priority tiers to guide future engineering sprints:

Priority 1: Critical (Must Resolve Before Pilot Launch)

  1. Enterprise Object Storage & Binary Virus Scanning: Implement S3/MinIO file storage with automated ClamAV scanning for UCreds imports, cohort readiness evidence, and SAMC QV evidence packages.
  2. Asynchronous Job Queue Infrastructure: Deploy Redis and Laravel Horizon to handle background imports (MD-06), 500-credential issuing batches (MD-09), and heavy regulatory reports (MD-15).
  3. Microsoft Entra ID Production SSO (OI-03): Transition from the development stub IdP to UTeM's official Microsoft Entra ID Single Sign-On gateway with hardware-backed MFA enforcement.

Priority 2: High (Important Functional & Compliance Gaps)

  1. Server-Side PDF Binary Compilation: Integrate Playwright Core / Chromium backend rendering to generate deterministic PDF binaries for official certificates, receipts, ACRs, and decision letters.
  2. Senate Transfer Decision Letter (DOC-12): Author the standardized A4 institutional letter template for approved credit transfers.
  3. Comprehensive Bahasa Melayu UI Localization: Complete full Malay translation across all table headers, input labels, error banners, and action buttons in lang/ms.json.

Priority 3: Medium (Workflow Continuity & Usability Improvements)

  1. Automated Re-Verification Task Initialization (FR-175): When an approved SAMC undergoes a material change, automatically seed a new draft QV record in qv_records.
  2. CQI Action to Change Request Bridge: Pre-fill change request fields when a lecturer clicks "Request Change" directly from an open CQI improvement action.
  3. Centralized Document Repository Integration: Ensure all formal notices (suspension notices, withdrawal confirmations) are linked within /documents.

Priority 4: Low (Minor Optimizations & Polish)

  1. Merge Printable Proposal & Senate Pack: Unify /proposals/{id}/print and /approvals/{id}/pack into a single reusable printable Blade view.
  2. Sidebar Count Enhancements: Add dynamic live badges to cohort and CQI sidebar items matching the approved prototype.
