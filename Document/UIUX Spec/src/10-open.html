10.3 Prototype Limits

  • The prototype runs in a browser with sample data kept for the browser tab; "Reset data" restores the starting state. It has no server, accounts or real integrations.
  • Screens show English text; the language switch works and is recorded, but BM strings are not written yet.
  • The QR code on certificates is a drawn placeholder; signatures and hashes are test values.
  • Excel export is marked Release 2; CSV and PDF are available.
  • Screens were checked automatically at desktop width; the phone layout follows the responsive rules but has not been reviewed screen by screen.
  • One sample learner appears in two Cloud Native Development cohorts; it does not affect any flow.
