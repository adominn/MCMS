4. Comprehensive Course Directory (The 60 Public Offerings)

4.1 Public Catalog Overview & Statistical Breakdown

The public UCreds catalog comprises exactly 60 curated offerings distributed across three functional types: ODL Academic Degree Programmes (3 offerings), Course Learning Paths (2 offerings), and Specialised Micro-Courses (55 offerings). The overall pricing structure ranges from completely free open-access modules to RM 150.00 for technical certifications, and up to RM 25,110.00 for full postgraduate degree tuition.

4.10 The Underlying Moodle Repository (214 Course Instances)

While the public catalog exposes 60 polished entry-points, direct inspection of the underlying Moodle core directory (/course/index.php) reveals 214 registered course instances. This deeper repository contains internal subject modules (such as the full MAXL and MECL series), faculty staging sandboxes, and modular assessment units that feed into the public micro-credentials.
