Verify Credentials & Digital Badges

Verify the authenticity of UTeM micro-credential certificates and digital badges online or via cryptographic file signature.

Method 1: Public Code

Search by Credential Code

Enter the 10-character code printed on the official certificate or digital badge transcript (e.g., CND01-7K9MJ).

Test sample codes: CND01-7K9MJ (Valid), SEC02-3X8PQ (Superseded), DATA9-1Z4TR (Revoked), BADGE-CND-M1-01 (Badge)
Method 2: Cryptographic Signature

Verify Cryptographic File

Upload a W3C Verifiable Credential (.json) or signed token (.jwt) to verify its signature against UTeM's Ed25519 public key.

Cryptographic Standards: W3C Verifiable Credentials 2.0 · Open Badges 3.0 · Ed25519 (EdDSA)
INTEGRITY & SECURITY]

How Cryptographic Verification Works

Every credential issued through UTeM MCMS is cryptographically signed using an asynchronous Ed25519 private key securely stored in UTeM's hardware security module (HSM). The cryptographic signature guarantees that the recipient name, completion outcomes, and credit values have not been modified or tampered with since issuance.
