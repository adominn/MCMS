Cloud Native Application Development & Microservices

Course Code: UMC-BITD-2401 · Cohort ID: CND-2027A · Discipline: Software Engineering & Cloud Computing

This micro-credential provides software developers, systems architects, and IT engineers with comprehensive hands-on competence in constructing container-based microservices. Participants learn to containerize polyglot backend services with Docker, manage scalable deployments on Kubernetes clusters, and automate deployment pipelines via GitHub Actions and ArgoCD.

Academic Credit & Transfer Notice This is an Unbundled Micro-Credential (UMC) derived from UTeM's Bachelor of Computer Science curriculum. Completing this offering earns 3 academic credits recorded on an official Academic Credit Record (ACR). Storage of credits in the Academic Bank of Credit (ABC) is storage only; articulation and exemption into degree programs requires formal Senate evaluation upon admission.
OUTCOMES Aligned with MQF 2.0 Domains

Course Learning Outcomes (CLOs)

CLO 1: Decompose monolithic legacy applications into decoupled, loosely-coupled microservice architectures using Domain-Driven Design (DDD). (MQF Domain 1: Knowledge & Understanding)
CLO 2: Implement automated container lifecycle operations, multi-stage Docker builds, and Kubernetes ingress and service mesh controllers. (MQF Domain 2: Cognitive Skills)
CLO 3: Configure secure CI/CD deployment pipelines with automated linting, vulnerability scanning, and Canary rollout strategies. (MQF Domain 3: Practical Skills)
